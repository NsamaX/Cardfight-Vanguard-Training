# รายการรหัสมาตรฐาน

รหัสกลางสำหรับเขียนความสามารถของการ์ดให้เป็นแบบเดียวกัน ไม่ว่าคำแปลบนการ์ดจะเขียนต่างกันแค่ไหน ข้อความจริงบนการ์ดยังเก็บไว้ในช่อง **ผล** ตามเดิม ส่วนรหัสในไฟล์นี้ใช้สำหรับค้นหาและจับคู่คอมโบ

รายการนี้ตั้งจากการ์ด 28 ไฟล์ในคลังตอนนี้ (ภาค G) ถ้าการ์ดใหม่มีเหตุการณ์หรือผลที่ยังไม่มีรหัส ให้เพิ่มรหัสในไฟล์นี้ก่อนใช้

## รูปแบบการเขียน

```
ชื่อรหัส(ค่าหลัก, ชื่อพารามิเตอร์=ค่า)
```

| ค่าที่ใช้บ่อย | ความหมาย |
|---|---|
| `self` | การ์ดใบนี้เอง |
| `other-own` | ยูนิทใบอื่นของเรา |
| `own-VC` | แวนการ์ดของเรา |
| `opp` | ฝ่ายคู่แข่ง |
| `VC` / `RC` / `GC` | ช่องบนสนาม |
| `hand` / `drop` / `deck` / `soul` / `damage` / `G` | มือ / ดรอปโซน / กองการ์ด / โซล / ดาเมจโซน / G โซน |
| `n` | จำนวน ใช้ `≤` ถ้าการ์ดเขียนว่า "ไม่เกิน" |

## 1. จังหวะ (เหตุการณ์ที่ทำให้ AUTO ทำงาน)

| รหัส | ความหมาย | ถ้อยคำบนการ์ด | การ์ดที่ใช้ |
|---|---|---|---|
| `enter(RC, self)` | ใบนี้เข้าสู่ RC (จากที่ไหนก็ได้) | "เมื่อยูนิทนี้เข้าสู่ช่อง (RC)" | เนโครเลซี่, โฮโนลี่, คีย์เวิร์ดฮอลโล่ว์ |
| `enter(RC, self, from=hand)` | ใบนี้เข้าสู่ RC จากมือ | "เมื่อยูนิทนี้เข้าสู่ช่อง (RC) จากมือคุณ" | ทอมมี่ |
| `enter(RC, self, from=drop)` | ใบนี้เข้าสู่ RC จากดรอปโซน | "เมื่อยูนิทนี้เข้าสู่ช่อง (RC) จากดรอปโซนคุณ" | พลปืนใหญ่โครงกระดูก, คิง·เซอเพนท์, ผีน้อยมิคฯ |
| `enter(RC, other-own, from=drop)` | ยูนิทใบอื่นของเราเข้าสู่ RC จากดรอปโซน | "เมื่อยูนิทคุณเข้าสู่ช่อง (RC) ช่องอื่นจากดรอปโซน" | ไนท์โรส แสงดารา |
| `enter(VC, self)` | ใบนี้เข้าสู่ VC (ไรด์หรือสไตรด์) | "เมื่อยูนิทนี้เข้าสู่ช่อง (VC)" | ไนท์สตอร์ม, โอบาไดอา, กัลเลียน, เมกิดโด้ |
| `enter(GC, self)` | ใบนี้เข้าสู่ GC (จากที่ไหนก็ได้) | "เมื่อยูนิทนี้**ลง**ช่อง (GC)" / "เมื่อยูนิทนี้**เข้าสู่**ช่อง (GC)" | จิน BT02, จั๊บปี้, เนโครลิลลี่, เนโครนอร่า, อากรีม, ดีพ คอร์ปส์ |
| `enter(GC, self, from=hand)` | ใบนี้เข้าสู่ GC จากมือ | "เมื่อยูนิทนี้เข้าสู่ช่อง (GC) จากมือคุณ" | พายุหมุนพิฆาตจิน |
| `stride(own)` | เราทำการสไตรด์ | "เมื่อ G ยูนิทคุณทำการ STRIDE" / "เมื่อคุณทำการ STRIDE G ยูนิท" | ไนท์โรส หมอกยามค่ำคืน, ไนท์โรส แสงดารา |
| `attack(self)` | ใบนี้โจมตี (เป้าหมายอะไรก็ได้) | "เมื่อยูนิทนี้โจมตี" | เนโครรูค |
| `attack(self, target=VC)` | ใบนี้โจมตีแวนการ์ด | "เมื่อยูนิทนี้โจมตีแวนการ์ด" | ซอมบี้ปลาวาฬ |
| `attack(own-VC)` | แวนการ์ดของเราโจมตี | "เมื่อแวนการ์ดของคุณโจมตี" | แรมเพจ·เชด |
| `battle-end(self, did=attack-VC)` | จบการต่อสู้ที่ใบนี้โจมตีแวนการ์ด | "เมื่อจบการต่อสู้ที่ยูนิทนี้โจมตีแวนการ์ด" | ไนท์สตอร์ม |
| `battle-end(self, did=attack)` | จบการต่อสู้ที่ใบนี้โจมตี | "เมื่อจบการต่อสู้ที่ยูนิทนี้โจมตี" | ความสามารถที่เมกิดโด้มอบให้ |
| `battle-end(self, did=boost-RC)` | จบการต่อสู้ที่ใบนี้บูสท์ให้เรียร์การ์ด | "เมื่อจบการต่อสู้ที่ยูนิทนี้ทำการบูสท์ให้เรียร์การ์ด" | เนโครโบน |
| `to-drop(own, from=RC)` | เรียร์การ์ดของเราใบไหนก็ได้ตกลงดรอปโซน | "เมื่อเรียร์การ์ดของคุณตกลงดรอปโซน" | ไนท์โรส หมอกยามค่ำคืน |
| `to-drop(self, from=RC, by=hollow)` | ใบนี้ตกจาก RC ลงดรอปโซนเพราะฮอลโล่ว์ | "เมื่อยูนิทนี้ตกลงช่องดรอปโซนคุณจากช่อง (RC) ด้วย/โดยความสามารถฮอลโล่ว์" | กรูนาช, ความสามารถที่เนโครเลซี่มอบให้ |
| `retired(self, from=RC)` | ใบนี้ถูกรีไทร์จาก RC | "เมื่อยูนิทนี้ถูกรีไทร์จากช่อง (RC)" | ความสามารถที่ผีน้อยมิคฯ มอบให้ |
| `discarded(self, from=hand, as=g-guardian-cost)` | ใบนี้ถูกทิ้งจากมือเป็นคอสต์คอล G การ์เดี้ยน | "เมื่อการ์ดใบนี้ถูกทิ้งจากบนมือเพื่อเป็นคอสต์ของการคอล G GUARDIAN" | ผีน้อย เดวย์ |
| `phase-start(battle, own)` | เริ่มแบทเทิลเฟสของเรา | "เมื่อเริ่มต้นช่วงแบทเทิลเฟสคุณ" | ไนท์โรส (G ยูนิท) |
| `turn-end` | จบเทิร์น | "เมื่อจบเทิร์น" | คีย์เวิร์ดฮอลโล่ว์, กัลเลียน |
| `ridden-upon(self)` | มีการ์ดไรด์ทับใบนี้ | (ในคีย์เวิร์ดผู้เริ่มต้น) | คีย์เวิร์ดผู้เริ่มต้น |
| `step(stride, own)` | สไตรด์สเต็ปของเรา (จังหวะของ STRIDE และ ULTIMATE STRIDE) | "-สไตรด์สเต็ป-" | G ยูนิททุกใบ |
| `step(guard, opp)` | การ์ดสเต็ปของเทิร์นคู่แข่ง (จังหวะของ G GUARDIAN) | "-ในช่วงการ์ดสเต็ปของเทิร์นคู่แข่ง-" | G การ์เดี้ยนทุกใบ |

## 2. เงื่อนไข

| รหัส | ความหมาย | การ์ดที่ใช้ |
|---|---|---|
| `GB(n)` | Generation Break n | หลายใบ |
| `1/turn` | ใช้ได้ 1 ครั้งต่อเทิร์น | ไนท์โรส หมอกยามค่ำคืน, ไนท์โรส แสงดารา, ไนท์โรส (G ยูนิท) |
| `own-turn` | เฉพาะในเทิร์นเรา ("ในเทิร์นคุณ") | ไนท์โรส หมอกยามค่ำคืน, ไนท์โรส แสงดารา |
| `self-hollowed` | ใบนี้ติดสถานะฮอลโล่ว์อยู่ | ไนท์สตอร์ม, ซอมบี้ปลาวาฬ, พลปืนใหญ่, เนโครรูค, ผีน้อยมิคฯ |
| `vc-name("ไนท์โรส")` | แวนการ์ดเรามีคำว่า "ไนท์โรส" ในชื่อ | เนโครเลซี่, เนโครโบน |
| `vc-name("ไนท์โรส") & vc-grade≥3` | แวนการ์ดเราเป็นเกรด 3 ขึ้นไปและมีคำว่า "ไนท์โรส" ในชื่อ | แรมเพจ·เชด |
| `vc-clan(แกรนบลู)` | แวนการ์ดเราเป็นแคลนแกรนบลู | แบนชีน้ำวน |
| `drop-count≤5` | ดรอปโซนเรามี 5 ใบหรือน้อยกว่า | ซอมบี้ปลาวาฬ (CONT ลด Power) |
| `name-in-drop("พายุหมุนพิฆาตจิน")` | มีการ์ดชื่อนี้ในดรอปโซน | พายุหมุนพิฆาตจิน |
| `attack-count≥5` | การโจมตีครั้งที่ 5 ขึ้นไปของเทิร์น | โฮโนลี่ |
| `while(stride-cost)` | ขณะจ่ายคอสต์สไตรด์ | ทอมมี่ |
| `called≥3` | คอลการ์ดจากผลนี้ได้ 3 ใบขึ้นไป | ไนท์โรส (G ยูนิท) |
| `hollow-milled≥2` | การ์ดที่มีฮอลโล่ว์ตกดรอปโซนจากผลนี้ 2 ใบขึ้นไป | โอบาไดอา |
| `called-has-hollow` | การ์ดที่คอลมามีความสามารถฮอลโล่ว์ | ไนท์โรส แสงดารา |
| `vc-grade=3 & G-faceup=0 & opp-vc-grade=2 & opp-no-ride-last-turn` | เงื่อนไขสไตรด์พิเศษ (การ์ดเขียนไว้ครบในช่อง ผล) | ซีบรีซ |

## 3. คอสต์

| รหัส | ความหมาย | การ์ดที่ใช้ |
|---|---|---|
| `CB(n)` | Counter Blast n | หลายใบ |
| `SB(n)` | Soul Blast n | ไนท์โรส แสงดารา, ไนท์สตอร์ม, เนโครเลซี่, เนโครนอร่า |
| `discard(n, filter)` | ทิ้งการ์ดจากมือ ตามเงื่อนไขของการ์ดนั้น | จิน ×2, ซีบรีซ, อากรีม, STRIDE, G GUARDIAN |
| `mill(n)` | ส่งการ์ดบนสุดของกองการ์ดลงดรอปโซน | ไนท์โรส หมอกยามค่ำคืน (3), ดีพ คอร์ปส์ (2) |
| `reveal(filter)` | แสดงการ์ดจากมือ | ทอมมี่ (เกรด 3) |
| `retire-own(n)` | รีไทร์เรียร์การ์ดของเรา | เนโครลิลลี่ |
| `soul-in(self)` | นำใบนี้เข้าโซล | แบนชีน้ำวน, แรมเพจ·เชด |
| `bind(filter)` | ไบนด์การ์ดแบบหงายหน้า | ผีน้อย เดวย์ (ใบนี้ + Heal Trigger อีกใบจากดรอปโซน) |
| `flip-G-up(filter)` | หงายการ์ดที่คว่ำอยู่ใน G โซน | เนโครนอร่า (G GUARDIAN), ไนท์โรส G ยูนิท (ชื่อเดียวกับใบนี้) |

## 4. ผล

| รหัส | ความหมาย | การ์ดที่ใช้ |
|---|---|---|
| `call(drop→RC, n, filter)` | คอลจากดรอปโซนลง RC | ไนท์โรส หมอกยามค่ำคืน, ไนท์โรส แสงดารา, ไนท์สตอร์ม, เนโครเลซี่, เนโครโบน, เนโครลิลลี่, โอบาไดอา, ไนท์โรส (G ยูนิท), กัลเลียน |
| ↳ `to=` ช่องที่คอลลงได้ | ไม่ระบุ = RC ไหนก็ได้ (มียูนิทอยู่ = คอลทับ) · `empty` = RC ที่ไม่มียูนิทอยู่ · `not-self` = RC ที่ไม่มียูนิทนี้อยู่ · `different` = คนละช่องกับใบที่คอลไปแล้วในผลนี้ · `same-column` = แนวเดียวกับยูนิทนี้ | เนโครลิลลี่ (`empty`), ไนท์สตอร์ม (`not-self`), ไนท์โรส (G ยูนิท) (`different`), โอบาไดอา (`same-column`) |
| `call(hand+drop→RC, n)` | คอลจากมือและดรอปโซนรวมกันลง RC | เมกิดโด้ (≤5) |
| `call(drop→GC, n, filter)` | คอลจากดรอปโซนลง GC | เนโครนอร่า (2 ใบเกรดต่างกัน) |
| `mill(n)` | ส่งการ์ดบนสุดของกองการ์ดลงดรอปโซน (ในฐานะผล) | ไนท์โรส แสงดารา (≤3) |
| `search(deck→drop, n, filter)` | ค้นกองการ์ดแล้วส่งลงดรอปโซน | โอบาไดอา (≤3), จั๊บปี้ (≤1 แกรนบลู) |
| `search(deck→hand, n, filter)` | ค้นกองการ์ดขึ้นมือ | ทอมมี่ (เกรด 3 "ไนท์โรส"), ไนท์สตอร์ม (ดู 5 ใบบนสุด เอาการ์ดที่มีฮอลโล่ว์) |
| `draw(n)` | จั่วการ์ด | พลปืนใหญ่, แรมเพจ·เชด, อากรีม, แบนชีน้ำวน |
| `retire(opp-RC, n)` | รีไทร์เรียร์การ์ดคู่แข่ง | พลปืนใหญ่ |
| `retire(own, target)` | รีไทร์ยูนิทของเรา (ในฐานะผล) | เนโครโบน (ยูนิทที่ถูกบูสท์) |
| `power(±X, target, until)` | เพิ่ม/ลด Power | หลายใบ |
| `shield(+X, self)` | เพิ่ม Shield | เนโครลิลลี่ (+10000), ดีพ คอร์ปส์ (+5000) |
| `critical(+n, target)` | เพิ่ม Critical | ไนท์โรส (G ยูนิท) |
| `no-hit(target)` | ยูนิทเป้าหมายไม่ถูกฮิทจนจบการต่อสู้ | พายุกระหน่ำ จิน, พายุหมุนพิฆาตจิน |
| `CC(n)` | Counter Charge | พายุหมุนพิฆาตจิน, กรูนาช, เดวย์, คิง·เซอเพนท์, ความสามารถที่เนโครเลซี่มอบให้ |
| `SC(n)` | Soul Charge | คิง·เซอเพนท์, เดวย์, ความสามารถที่เนโครเลซี่มอบให้ |
| `damage-facedown(n)` | คว่ำการ์ดหงายในดาเมจโซน (ในฐานะผล ไม่ใช่คอสต์) | โฮโนลี่ |
| `hollow(target)` | ทำให้ติดสถานะฮอลโล่ว์ | คีย์เวิร์ดฮอลโล่ว์, ไนท์โรส (G ยูนิท) คอลในสภาพฮอลโล่ว์ |
| `grant(ability, target, until)` | มอบความสามารถให้ยูนิท | เนโครเลซี่, ผีน้อยมิคฯ, เมกิดโด้ |
| `return-to-deck(self)` | นำใบนี้กลับกองการ์ดแล้วสลับ | ความสามารถที่ผีน้อยมิคฯ มอบให้ |
| `swap(self, other-own-RC)` | สลับตำแหน่งยูนิท | ความสามารถที่เมกิดโด้มอบให้ |
| `grade(+n, self)` | ปรับเกรด | ทอมมี่ (+2 ขณะจ่ายคอสต์สไตรด์) |
| `attack-tax(CB(1), RC)` | เรียร์การ์ดต้องจ่ายคอสต์ก่อนโจมตีแวนการ์ด | โฮโนลี่ |
| `stride-from-G(self)` | สไตรด์ด้วยวิธีพิเศษจาก G โซน | ซีบรีซ |

| `all-clan(self)` | นับเป็นทุกแคลนและทุกเนชั่น | โฮโนลี่, อากรีม, ซีบรีซ |
| `stride(self)` | สไตรด์การ์ดใบนี้ลง VC (ผลของ STRIDE) | G ยูนิททุกใบ |
| `call(G→GC, self)` | คอลใบนี้จาก G โซนลง GC (ผลของ G GUARDIAN) | G การ์เดี้ยนทุกใบ |
| `call(self→RC)` | คอลใบนี้ลง RC (ผลของผู้เริ่มต้น) | กรูนาช |
| `discard(n)` | ทิ้งการ์ดจากมือ (ในฐานะผล ไม่ใช่คอสต์) | ทอมมี่ |
| `choose(A, B)` | เลือกผลอย่างใดอย่างหนึ่ง | เดวย์ (CC1 หรือ SC1), ความสามารถที่เนโครเลซี่มอบให้ (CC1 / SC1) |
| `keyword(ชื่อ)` | คีย์เวิร์ดที่ไม่มีผลระหว่างเกม มีแค่กฎจัดเด็ค | พิทักษ์ (จิน ×2) |

### ตัวช่วยใน filter และ n

| รหัส | ความหมาย | ตัวอย่าง |
|---|---|---|
| `name("คำ")` | การ์ดที่มีคำนี้ในชื่อ | `filter=grade-3 & name("ไนท์โรส")` |
| `count-in-drop(filter)` | จำนวนการ์ดในดรอปโซนที่ตรง filter | `n=count-in-drop(name("ไนท์โรส"))` |
| `if=เงื่อนไข` | ผลนี้เกิดเฉพาะเมื่อเงื่อนไขเป็นจริง | `draw(1, if=self-hollowed)` |
| `until=` | ระยะเวลาของผล: `battle-end` จบการต่อสู้, `turn-end` จบเทิร์น | `power(+2000, self, until=turn-end)` |
| `at=` | ผลเกิดภายหลังตามจังหวะที่ระบุ | `retire(self, at=turn-end)` |

## 5. ผลที่ไปเปิดจังหวะของใบอื่น (หัวใจของการหาคอมโบ)

ผลหรือคอสต์ทางซ้ายทำให้เกิดเหตุการณ์ทางขวา การ์ดที่มีจังหวะตรงกับเหตุการณ์นั้นจะทำงานต่อ

| ผล / คอสต์ / กฎ | ทำให้เกิด | การ์ดที่รอเหตุการณ์นี้ |
|---|---|---|
| `call(drop→RC)` | `enter(RC, self, from=drop)` และ `enter(RC, other-own, from=drop)` | พลปืนใหญ่, คิง·เซอเพนท์, ผีน้อยมิคฯ, ไนท์โรส แสงดารา |
| `call(…→RC)` ทุกแบบ และการคอลปกติจากมือ | `enter(RC, self)` | เนโครเลซี่, โฮโนลี่, คีย์เวิร์ดฮอลโล่ว์ |
| คีย์เวิร์ดฮอลโล่ว์ (รีไทร์ตอนจบเทิร์น) | `retired(self, from=RC)`, `to-drop(self, from=RC, by=hollow)`, `to-drop(own, from=RC)` | ผีน้อยมิคฯ (ที่ได้รับความสามารถ), กรูนาช, เนโครเลซี่ (ที่ได้รับความสามารถ), ไนท์โรส หมอกยามค่ำคืน |
| `retire-own` (คอสต์) / `retire(own)` (ผล) | `retired(…, from=RC)`, `to-drop(own, from=RC)` | ไนท์โรส หมอกยามค่ำคืน, ผีน้อยมิคฯ (ที่ได้รับความสามารถ) |
| STRIDE ทุกแบบ | `stride(own)`, `enter(VC, self)` ของ G ยูนิท | ไนท์โรส หมอกยามค่ำคืน, ไนท์โรส แสงดารา, โอบาไดอา, กัลเลียน, เมกิดโด้ |
| ทิ้งเดวย์เป็นคอสต์ G GUARDIAN | `discarded(self, as=g-guardian-cost)` | ผีน้อย เดวย์ |
| `mill`, `search(deck→drop)`, คอสต์ `discard` | จำนวนการ์ดในดรอปโซนเพิ่ม และมีเป้าหมายให้คอลจากดรอปโซน | ซอมบี้ปลาวาฬ (`drop-count`), พายุหมุนพิฆาตจิน (`name-in-drop`), ไนท์โรส (G ยูนิท) (นับชื่อ "ไนท์โรส" ในดรอปโซน), ทุกใบที่มี `call(drop→…)` |
| `flip-G-up`, G ยูนิทกลับ G โซนตอนจบเทิร์น, G การ์เดี้ยนกลับ G โซนหลังการต่อสู้ | การ์ดหงายหน้าใน G โซนเพิ่ม ทำให้นับ `GB(n)` ได้เร็วขึ้น | ทุกใบที่มี `GB(n)`, อัลติเมทสไตรด์ (ต้องการหงายหน้า 3 ใบขึ้นไป) |

### ตัวอย่างการไล่คอมโบจากตาราง

1. เรียร์การ์ดที่ติดฮอลโล่ว์ถูกรีไทร์ตอนจบเทิร์น เกิด `to-drop(own, from=RC)`
2. **ไนท์โรส หมอกยามค่ำคืน** (VC, GB2, 1/turn) ทำงาน จ่าย `mill(3)` แล้วคอลการ์ดใบนั้นกลับลง RC
3. การคอลครั้งนี้เกิด `enter(RC, self, from=drop)` ถ้าการ์ดใบนั้นคือ**พลปืนใหญ่โครงกระดูก** จะทำงานต่อ (GB1, CB1): รีไทร์เรียร์การ์ดคู่แข่ง และจั่วการ์ดถ้าติดฮอลโล่ว์

การ `mill(3)` ในขั้นที่ 2 ยังเพิ่มการ์ดในดรอปโซนให้ซอมบี้ปลาวาฬและไนท์โรส (G ยูนิท) ด้วย

ลำดับตามกฎของตัวอย่างนี้ดูได้ที่ [timing-g.md](timing-g.md) (ข้อสังเกตข้อ 1–2): ในเอนด์เฟส G ยูนิทกลับ G โซนก่อนฮอลโล่ว์รีไทร์ ไนท์โรสจึงทำงานได้แม้เทิร์นนั้นสไตรด์ และยูนิทที่ถูกคอลกลับไม่ต้องเลือกติดฮอลโล่ว์
