# เครื่องมือ (`tools/`)

สคริปต์ Python ทั้งสองตัวต้องใช้ PyYAML และ `clean_images.py` ต้องใช้ numpy กับ Pillow เพิ่ม

## find_chains.py

ค้นหาวงจรคอมโบจากรหัสในไฟล์การ์ด ไล่ว่าความสามารถหนึ่งก่อเหตุการณ์อะไร และการ์ดใบไหนรอเหตุการณ์นั้น (ใช้ตารางในหัวข้อ 5 ของ [vocabulary.md](vocabulary.md))

```
python tools/find_chains.py                                   # เทิร์นคู่แข่ง เริ่มจาก G GUARDIAN
python tools/find_chains.py --vc "หมอกยามค่ำคืน" --gb 2        # ระบุแวนการ์ดและ GB
python tools/find_chains.py --turn own --start "โอบาไดอา"      # เทิร์นเรา เริ่มจากการ์ดที่ระบุ
```

| ตัวเลือก | ความหมาย |
|---|---|
| `--turn opp` / `own` | เทิร์นของใคร (ค่าเริ่มต้น: เทิร์นคู่แข่ง) |
| `--start` | เริ่มจากการ์ดที่ชื่อมีคำนี้ (ไม่ระบุ = จุดเริ่มต้นมาตรฐานของเทิร์นนั้น) |
| `--vc` | ชื่อ (บางส่วน) ของแวนการ์ด ใช้ตัดความสามารถ (VC) ของใบอื่นออก |
| `--gb` | จำนวน GB ที่มี ใช้ตัดความสามารถที่ต้องการ GB สูงกว่า |
| `--depth` | ไล่ลึกสุดกี่ชั้น (ค่าเริ่มต้น 6) |

ท้ายแต่ละบรรทัดแสดงยอดสะสมของเส้นทางนั้น เช่น `{CB 2, SB 1 | ได้คืน CC+1, SC+1}`
- **CB / SB:** คอสต์ที่ต้องจ่ายรวมตั้งแต่ต้นทาง (CB นับรวมผลที่คว่ำดาเมจของเราเองด้วย)
- **ได้คืน:** CC / SC ที่ได้ระหว่างทาง ระบุว่า "มีเงื่อนไข" ถ้าได้เฉพาะบางกรณี และ "เลือก" ถ้าต้องเลือกอย่างใดอย่างหนึ่ง

สิ่งที่สคริปต์ยังไม่ตรวจ: จำนวนช่องว่างบน RC และการ์ดที่มีอยู่จริงในดรอปโซน

## clean_images.py

ทำรูปการ์ดและรูปสลีฟจากรูปต้นฉบับ ไฟล์ต้นฉบับไม่ถูกแก้ไข และทำใหม่ทุกใบทุกครั้งที่รัน

```
python tools/clean_images.py      # การ์ด: .temp/ → public/images/   สลีฟ: .temp/sleeves/ → public/sleeves/
```

| | การ์ด | สลีฟ |
|---|---|---|
| รายการไฟล์ | `SOURCES`: `"ชื่อไฟล์ต้นฉบับ": "ชื่อการ์ดไทย"` (ต้องตรงกับ `name` ในไฟล์การ์ด) | `SLEEVES`: `"ชื่อไฟล์ต้นฉบับ": "ชื่อสลีฟ"` |
| ตัดพื้นหลังรอบรูป | ✓ | ✓ |
| ขนาด | 544×793 | 440×640 (ตัดส่วนเกินจากกึ่งกลาง ไม่ยืดภาพ) |
| ปรับแสงและความสดของสี | ✓ | — |
| มุมมนโปร่งใส | ✓ | — |
| ไฟล์ผลลัพธ์ | `public/images/<รหัสการ์ด>.png` | `public/sleeves/<ชื่อสลีฟ>.jpg` |

ขั้นตอนเต็มของการเพิ่มการ์ดหรือสลีฟใหม่ ดู [add-card.md](add-card.md)
